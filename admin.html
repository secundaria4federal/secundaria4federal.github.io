Conexión con GitHub

Para guardar cambios reales en la página, este panel necesita un token de acceso personal de GitHub con permiso de escritura sobre este repositorio. El token queda guardado solo en este navegador — nunca se sube al sitio. Sin un token válido podés ver el panel, pero no vas a poder guardar nada.

¿Cómo genero mi token de GitHub? (una sola vez)
  1. Entrá a GitHub con tu cuenta y andá a Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Hacé clic en Generate new token. Ponele un nombre, por ejemplo "Panel Escuela N°4".
  3. En Resource owner elegí la organización/cuenta dueña del repositorio (secundaria4federal).
  4. En Repository access elegí Only select repositories y seleccioná únicamente secundaria4federal.github.io.
  5. En Permissions → Repository permissions, buscá Contents y elegí Read and write.
  6. Generá el token y copialo (empieza con github_pat_). Pegalo acá arriba — no vas a poder verlo de nuevo en GitHub, así que guardalo en un lugar seguro (ej. un gestor de contraseñas).

Conectá tu token de GitHub para empezar a editar los contenidos y la galería.
